# 計測中バナーの時刻表示を拡大する 設計書

## 背景

計測中バナーの経過時刻は、モバイル幅（≤560px）では活動名と同じ行に 30px で表示され、
2件以上の同時計測（`multi` モード）では 22px まで縮む。時刻はバナーの中で最も見たい
情報なのに、活動名やボタンと同格の扱いになっていて視認性が低い。

## 方針

行のレイアウトを**縦積み**に統一する。活動名を小さなラベルとして上に置き、その下に
時刻を全幅で大きく（44px）表示し、ボタン行を最下段に置く。

- **画面幅で構造を変えない**: 現状はモバイル幅だけ「名前と時刻を同じ行に並べる」
  flex 指定があり、デスクトップと形が違う。縦積みに統一すればこの分岐ごと消える。
- **`multi` モードでも時刻は同じ 44px**: 一覧性より視認性を優先する（利用者の選択）。
  行の `padding` を詰める既存の緩和は残し、高さの伸びを抑える。
- 時刻の `tabular-nums` と `font-weight: 300` は現状を維持する。

### 却下した案

1. **ボタンのアイコン化で横スペースを確保**: バナーの高さは保てるが、拡大幅が
   36〜40px 止まりで、ボタンの意味も分かりにくくなる。
2. **タップで全画面タイマー表示**: 最も大きくできるが、実装量が最大で、見るために
   ワンタップ必要になる。常時見えていることがバナーの価値なので採用しない。

## 実装

変更は `index.html` のインライン CSS のみ。行の HTML 構造（`.rb-head` 内で
`.rb-name` と `.rb-time` が縦に並ぶ）は既に縦積みと同じ形なので、`app.ts` は変更しない。

- `.rb-row` を全幅で縦方向（`flex-direction: column`）にし、`.rb-actions` を右寄せで
  最下段に置く
- `.rb-name` は 14px・やや控えめな白（透明度を下げる）にして時刻へ視線を誘導する
- `.rb-time` を 44px にする
- `#runningBanner.multi .rb-time { font-size: 22px }` の縮小ルールを削除する
  （`.multi .rb-row` の `padding` 縮小は残す）
- `@media (max-width: 560px)` 内の `.rb-head` を横並びにする指定を削除する
  （縦積みへの統一で不要になるため）

バナーが縦に伸びても、最下部カードが隠れない余白は `renderBanner()` が
`offsetHeight` を実測して確保しているため追従は自動である。

## リリース

- ユーザーに見える変更なので `package.json` の `version` を 1.3.3 → 1.3.4 に上げる
- `index.html` は network-first で配信されるため `sw.js` の `CACHE` バンプは不要

## テスト

`mise exec -- npm run build` で TS のコンパイルが通ることを確認した上で、
ローカルサーバーで以下をモバイル幅・デスクトップ幅の両方で目視確認する。

1. 単独計測: 名前ラベルの下に 44px の時刻、最下段にボタン行が出る
2. 2件同時計測: 両方の行が同じ 44px で表示され、行間が詰まる
3. 一時停止混在: 一時停止行の暗転（`.rb-row.paused`）が縦積みでも機能する
4. 長い活動名（40字上限）: 名前が折り返してもボタン寸法と時刻が崩れない
